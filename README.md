# InfernoX — Premium Gaming Platform

A premium black gaming-platform frontend built for Replit.

## Run
Open the project in Replit and run it with any static server, or simply preview `index.html`.

## Included
- Premium responsive black/orange UI
- Hero, featured games, game library, categories and CTA
- Search
- Genre/platform/sort filters
- Game details modal
- Publish Game form
- Local admin dashboard
- Feature/unfeature games
- Delete games
- Browser localStorage persistence
- Mobile navigation
- Responsive layouts

## Important
This version is a working frontend/local demo. The Admin panel stores game changes in the browser using localStorage.

For production, connect:
- Authentication
- A real database
- Cloud image/file storage
- Server-side game submission moderation
- Real download URLs
- Secure admin authorization

No specific game is included; the sample titles are generic placeholders and can be removed/replaced from the admin/data layer.
